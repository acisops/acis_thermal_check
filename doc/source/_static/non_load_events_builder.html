Non-Load Events Builder

Build a non_load_events file for acis_thermal_check — used with --state-builder=kadi --non_load_events <file> to add in maneuvers, ECS measurements, or an obsid change into a thermal model run.

File format reference
  • Whitespace/tab-delimited ASCII table with a commented header: # event_type  date  params
  • date is Chandra day-of-year, UTC: YYYY:DDD:HH:MM:SS.sss (fractional seconds optional).
  • MAN params: either 4 quaternion components q1,q2,q3,q4, or ra,dec,roll in degrees — comma-separated, no spaces.
  • ECS params: cap,hours — CAP id is one of 2, 3A, 3B, 4, 4ALT, 5, 6 (CCD count/config), hours is the RTS duration (max 39 hours).
  • OBSID params: the obsid number by itself, greater than 38000 and no larger than 65535.
